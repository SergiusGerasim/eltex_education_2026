для хранения данных использовался двухсвязный упорядоченный список.

**упорядоченный лексиграфически по фамилиям**

# задание сделано:
- добавленна обратная ссылка:
```c
struct phone_book_node *next;
struct phone_book_node *previous;
```

- добавление новго контакта происходит через лексиграфическое сравнение фамилий с помощью 
```c
strcmp() <= 0;
```
новый контакт может быть вставлен как в конец, так и в начало или середину.
