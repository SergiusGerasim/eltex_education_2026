# Формулировка задания 4 
#семафоры #разделяемая_память #System_V #имитация_односвязного_списка

- Модель "Производитель-Потребители".
- Процесс-производитель периодически генерирует массивы из
случайного количества случайных чисел и записывает их в разделяемую
память. 
- Перед массивом указывается количество элементов в нем и адрес
следующего блока данных. 
- Если блок данных является последним, адрес
следующего блока устанавливается равным 0. 
- Генерация наборов чисел завершается, когда исчерпывается объем разделяемой памяти. 
- Потребитель проверяет, что все наборы чисел обработаны, отключает разделяемую память
и завершает работу. 
- Если еще не все наборы обработаны, производитель
"засыпает" на некоторое время, после чего снова проверяет, завершилась ли
обработка.
- Процесс-потребитель считывает данные из памяти и анализирует их: в
каждом наборе находит максимальное и минимальное число и выводит эти
значения на экран. 
- Далее помечает набор как обработанный, указывая
количество элементов в нем, равное 0. Чтение выполняется периодически.
- Проанализировав один необработанный набор чисел, потребитель "засыпает"
на некоторое время.
- Может быть запущено несколько экземпляров потребителей.
- Доступ к разделяемой памяти управляется семафором.

## Сборка

```bash
make
```

Исполняемый файл и остальные артефакты сборки создаются в каталоге `build/`.

Очистка сборки:

```bash
make clean
```

## Запуск

Программа имеет два режима:

```text
./build/module3_task4 producer [segment_size] [generation_interval] [check_interval] [min_length] [max_length] [min_value] [max_value]
./build/module3_task4 consumer [read_interval]
```

### Параметры производителя

Параметры являются позиционными и указываются строго в приведённом порядке:

1. `segment_size` — размер сегмента разделяемой памяти в байтах.
2. `generation_interval` — пауза между генерацией массивов в секундах.
3. `check_interval` — пауза между проверками завершения обработки в секундах.
4. `min_length` — минимальное количество чисел в массиве, больше нуля.
5. `max_length` — максимальное количество чисел в массиве, не меньше `min_length`.
6. `min_value` — минимально возможное значение случайного числа.
7. `max_value` — максимально возможное значение случайного числа, не меньше `min_value`.

Пример:

```bash
./build/module3_task4 producer 4096 1 2 10 20 -100 100
```

Без дополнительных параметров используются значения по умолчанию:

```text
segment_size = 4096
generation_interval = 1
check_interval = 1
min_length = 1
max_length = 10
min_value = -100
max_value = 100
```

### Параметры потребителя

`read_interval` — пауза в секундах после обработки одного массива или проверки отсутствия доступных данных.

Пример:

```bash
./build/module3_task4 consumer 1
```

Без параметра интервал равен одной секунде.

## Пример совместного запуска

Сначала в первом терминале запускается производитель:

```bash
./build/module3_task4 producer 4096 1 2 10 20 -100 100
```

Затем запускается потребитель:

```bash
./build/module3_task4 consumer 1
```

Производитель после заполнения памяти ожидает, пока потребители обработают все опубликованные блоки. Поэтому запуск только производителя без потребителя будет выглядеть как ожидание.


Несколько потребителей:

```bash
./build/module3_task4 producer 4096 1 2 10 20 -100 100 &
./build/module3_task4 consumer 1 &
./build/module3_task4 consumer 1 &
wait
```
