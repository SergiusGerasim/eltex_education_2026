# Возможная структура тестов

```text
tests/
├── README_TEST.md
├── test_cli.sh
├── test_routing.sh
├── test_shutdown.sh
├── test_queue_removal.sh
└── send_raw_message.c
```

- `test_cli.sh` — корректные и ошибочные аргументы запуска.
- `test_routing.sh` — маршрутизация по темам, несколько подписчиков и несколько тем.
- `test_shutdown.sh` — завершение брокера, отправка `SIGINT` клиентам и удаление очереди.
- `test_queue_removal.sh` — завершение клиентов после внешнего удаления очереди.
- `send_raw_message.c` — отправка некорректных и граничных сообщений для проверки парсера.

Каждый shell-тест должен ограничивать время выполнения, сохранять вывод процессов во временный каталог и через `trap` завершать запущенные процессы. Существующую до начала теста очередь удалять автоматически нельзя.
