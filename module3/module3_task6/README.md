# Формулировка задания 6 
#UDP_сокеты

- Реализовать групповой чат с использованием широковещательной
рассылки через UDP-сокет. 
- Клиенты равноправные (одно приложение).
- При подключении (запуске программы) клиент рассылает
широковещательное сообщение. 
- Другие подключенные клиенты отображают
сообщение, что в сети появился новый участник. 
- Далее сообщения,
отправляемые клиентами, принимают остальные клиенты. 
- При отключении
приложение отправляет сообщение, что оно не в сети.
- Рекомендуется пересылать сообщения по физической сети, или
виртуальной сети между виртуальными машинами.

## Реализация

Программа представляет собой равноправный UDP-клиент для Linux. Каждый экземпляр привязывается к общему UDP-порту, отправляет сообщения на
широковещательный IPv4-адрес и одновременно ожидает пользовательский ввод и входящие датаграммы через `poll()`.

Используются три типа сообщений:

- `JOIN` — клиент появился в сети;
- `MESSAGE` — пользовательское сообщение;
- `LEAVE` — клиент завершает работу.

Каждый запуск получает случайный 64-битный идентификатор. Полученные сообщения с собственным идентификатором игнорируются.

## Сборка

```bash
make
```

Исполняемый файл создаётся в каталоге `build/`:

```text
build/module3_task6
```

## Запуск

```text
./build/module3_task6 <name> [broadcast_address] [port]
```

По умолчанию используются:

```text
broadcast_address = 255.255.255.255
port = 5000
```

Для локальной проверки в Linux или WSL в двух терминалах:

```bash
./build/module3_task6 Alice 127.255.255.255 5000
```

```bash
./build/module3_task6 Bob 127.255.255.255 5000
```


Для обмена по физической или виртуальной сети следует передать широковещательный адрес соответствующей подсети, например:

```bash
./build/module3_task6 Alice 192.168.1.255 5000
```

Все клиенты должны использовать одинаковые broadcast-адрес и порт. Доставку UDP могут ограничивать настройки сети и межсетевого экрана.

## Тесты

Запуск всех тестов:

```bash
make test
```

Отдельные проверки:

```bash
make test-protocol
make test-chat
```

Тесты проверяют бинарный протокол, локальную UDP broadcast-доставку, подключение двух клиентов, передачу сообщения и уведомление об отключении.
